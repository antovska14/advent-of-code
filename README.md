# 🎄 Advent of Code

My JavaScript solutions to [Advent of Code](https://adventofcode.com), the yearly Christmas-themed programming puzzles.

## Structure

```
2025/
  day01/
    solution.js
    input.txt
  day02/
  ...
2024/
  day01/
  ...
```

## Run

```bash
node 2025/day01/solution.js
```

## Inputs

Puzzle inputs aren't included (per AoC's request). Save your own as `input.txt` in each day's folder.

Happy coding! ⭐
